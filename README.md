# Desvie dos Blocos

Jogo em Python e Pygame mostrado no vídeo **Desvie dos Blocos**.
Mova o jogador azul para escapar dos blocos vermelhos. Cada bloco que passa
vale um ponto; ao encostar em um bloco, a pontuação volta a zero.

## Como executar

Tenha o Python instalado. Na pasta do repositório, execute:

```bash
python -m pip install -r requirements.txt
python desvie_dos_blocos.py
```

No Windows, se o comando `python` não funcionar, use `py` no lugar dele.

Use as setas **←** e **→** para mover o jogador. Feche a janela para sair.

## Código passo a passo

O arquivo `desvie_dos_blocos.py` contém o jogo completo. A pasta `passos/`
mostra as quatro versões executáveis apresentadas no vídeo: janela, jogador,
blocos e pontuação.
